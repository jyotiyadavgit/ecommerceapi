A simple e-commerce application where customers can order products. Our application contains the following services:

Product Servic
Order Service
Inventory Service
Notification Service

To focus on the principles of Spring Cloud and Microservices rather than creating fully-featured e-commerce services
Concepts include:
Synchronous Inter-Service Communication Pattern using Spring Cloud Open Feign
Service Discovery Pattern using Spring Cloud Netflix Eureka
API Gateway Pattern using Spring Cloud Gateway
